# CaseLens

> **SYNTHETIC DATA NOTICE:** every case, person, plate, phone number, and file in this repository is
> fictional and generated by `data_gen/`. No real case data is used, ever.

CaseLens is an evidence-search copilot. Upload a mixed case file (PDFs, audio, video, CSV) and ask questions
in plain English. Answers come back as a cited, auditable timeline: every claim links to its source page,
timestamp, frame, or row, and the system says "insufficient evidence" instead of guessing.

**Status:** Week 1, Foundations. Contracts and scaffold only; there are no features yet.

## Repo layout

| Path | What |

## Local development

Requirements: Python 3.11, Node 20+ with pnpm, Docker, and GNU make (on Windows, `mingw32-make` works).

```
make install   # Python venv + web deps
make up        # Postgres 16 + pgvector, MinIO
make migrate   # apply the schema
make test      # all tests
make lint      # ruff, mypy, eslint, tsc
make eval      # eval harness (stub)
```

Contributor and agent rules are in `CLAUDE.md`.
